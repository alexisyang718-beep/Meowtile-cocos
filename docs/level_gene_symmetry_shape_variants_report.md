# Level Gene 对称类型与形状族扩展记录

更新时间：2026-07-07

## 用户反馈

用户指出：

1. 镜像不只有左右，还包括上下、对角、中心对称等。
2. 当前 15 个候选暴露出样式太单一：同一个 gene 的几个 seed 看起来几乎一样，只是上层覆盖略不同。
3. 希望生成山型、M 型、N 型、S 型等更多不同形状。

## 本次修正

### 1. 增加多种对称模式

生成器现在支持以下结构对称：

| 模式 | 含义 |
|---|---|
| `lr` | 左右轴对称 |
| `ud` | 上下轴对称 |
| `rot` | 中心旋转对称 |
| `quad` | 左右 + 上下 + 中心对称 |
| `diag` | 对角对称，仅正方形网格可用 |

由于当前主要尺寸是 `6×7 / 7×8 / 8×9`，大多数不是正方形，因此对角对称不会强行用于非正方形棋盘，避免形变。

### 2. 增加形状族

生成器新增形状族：

- `soft_arch` 柔和拱形
- `mountain` 山型
- `m_shape` M 型 / 双峰
- `u_shape` U 型
- `n_shape` N 型
- `ring` 回字 / 中央洞
- `double_arch` 双拱
- `hourglass` 沙漏
- `s_shape` S 型
- `four_corners` 四角结构

不同 gene 会从适合自己的形状池里按 seed 选择变体。

### 3. 同 seed 扰动仍保持对称

原来的扰动只做左右镜像增删。现在改为：

```text
按当前 symmetry orbit 增删
```

因此无论是左右、上下、中心旋转，扰动后仍保留对应对称性。

### 4. 高度层也跟随当前对称模式

`h2 / h3` 的选择不再只用左右 pair，而是使用当前对称模式的 orbit。

这样上层高度不再只会左右镜像，也可以产生上下、中心对称等结构。

### 5. 堆叠方向跟随对称模式

真实 Cocos 偏移方向现在会按高度图主对称模式约束：

- 左右对称：X 方向镜像，Y 方向一致
- 上下对称：Y 方向镜像，X 方向一致
- 中心对称：X/Y 都镜像
- 四向对称：同时应用左右和上下约束

## 小批量验证

运行：

```bash
python3 level_workbench/tools/generate_from_gene.py --clean --seeds-per-gene 3
```

生成：

```text
5 个 gene × 3 个 seed = 15 个候选
```

验证结果：

- 同一 gene 内没有重复高度图。
- 每个候选至少满足一种对称：左右 / 上下 / 中心旋转。
- 已出现多种对称组合：
  - LR
  - ROT
  - LR+UD+ROT
- `gene_ch3_large_board` 的 3 个 seed 已明显不同：山型 / 四角 / 旋转结构。
- `gene_intro_gate`、`gene_intro_soft_arch` 不再只是同一个轮廓换上层覆盖。

## 当前候选预览

路径：

`level_workbench/generated/level_gene_candidates/index.html`

注意：

- 当前候选卡片仍主要显示高度图。
- 后续还需要把候选页升级为“高度图 + 真实偏移预览”。
- Validator 仍是 v0.1，`valid=0` 主要因为 opening flow 还没被生成器主动保证，不代表结构不可用。

## 下一步建议

接下来应该做两件事：

1. **升级候选预览**
   - 每张卡同时显示高度图和真实偏移预览。

2. **加入 opening flow 约束**
   - 开局 2-3 组可消。
   - 前 4 步不断流。
   - 第 5 步小门槛。

这样候选才会从“结构看起来合理”进入“玩法也有可能合理”。
