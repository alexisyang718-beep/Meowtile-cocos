# 普通棋盘图案数量与层级分布规则

## 结论

已将普通棋盘图案规则调整为：

1. 同一个图案在同一关最多出现 `2` 组三消，也就是最多 `6` 个 tile。
2. 每个图案数量必须是 `3` 的倍数。
3. 优先让每个图案只出现 `1` 组三消，也就是 `3` 个 tile。
4. 只有当关卡三消组数超过可用图案素材数时，才允许少量图案出现第二组三消。
5. 图案分布按层级控制难度，不再运行时无约束随机重洗。

## 层级分布规则

### 单组三消，3 个 tile

- 简单：`3`
  - 3 个都在同一层，更容易发现。
- 中等：`2 + 1`
  - 拆到两层，需要玩家先清一部分。
- 更难：`1 + 1 + 1`
  - 拆到三层，寻找成本更高。

### 两组三消，6 个 tile

- 简单：`3 + 3`
  - 两组三消分别落在不同层。
- 中等：`3 + 2 + 1`
  - 一组完整，另一组被拆散。
- 更难：`2 + 2 + 1 + 1`
  - 更分散，跨更多层。
- 后期多层：`2 + 1 + 1 + 1 + 1`
  - 更强的层级寻找难度。

下一步建议重点体验：

- 第1关、第4关、第8关：确认早期图案是否不再重复。
- 第24关、第55关：确认中期普通棋盘是否更丰富。
- 第120关、第240关、第320关：确认后期图案数量是否过多或识别压力过大。

如果你觉得图案太多导致识别成本太高，可以把规则从“尽量每图案 3 个”调整为“中后期允许更多图案 6 个”，但仍保持单图案最多 `6`。
