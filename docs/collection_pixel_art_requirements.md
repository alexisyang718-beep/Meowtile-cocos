# Collection 像素拼豆图制作规格

## 核心规则：颜色组数 = 关卡数

正式 Collection 需要 **23 张图**。每张图对应一个子章节，**该子章节有几关，最终用于解锁的颜色组就必须有几组**。例如 `Kitty Face, level 1-4` 是 4 关，所以最终可解锁颜色组就是 **4 组**，而不是 8-10 色。

这里的“颜色组”指游戏进度里每关填充的一组区域；豆豆的高光、阴影、描边、底座质感可以由后续转换/代码生成，不计入解锁颜色组。

## 图片交付位置

```text
assets/resources/newtheme/collection_beads/{puzzleId}.png
```

## 单张图通用要求

- 推荐尺寸：`1024 x 768` PNG，4:3 横图。

- 图片内自带：米白色长方形底座、深色/棕色细边框、中央像素拼豆图案。

- 不要把标题文字画进图片里，标题由代码显示。

- 基础像素网格建议：`32x32` 到 `48x48`，推荐 `40x40`。

- 每个颜色组要尽量是语义区域，例如“轮廓”“脸部”“耳朵”“毛线球”，不要随机噪点。

- 如果画面需要更丰富的视觉层次，请在同一颜色组内做豆豆高光/暗部，不要新增独立解锁色。

## 后续转换规则

你给最终 PNG 后，我会基于图片生成 `config/beads/{puzzleId}.json`，并把每张图按对应关卡数切成同等数量的 `groupId`。每关完成后解锁一个 `groupId`，也就是填充一组颜色/区域。
