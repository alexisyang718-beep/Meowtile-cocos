# 开局流、空间动线与关键 tile 设计原则

更新时间：2026-07-06

## 1. 用户提出的新原则

用户提出的核心观察：

1. 第一眼能消掉的大概是 `2-3` 组，也就是 `6-9` 个砖块。
2. 前 `4` 步应该基本能持续消除：
   - 可以是一屏里同时有 `3-4` 组能消；
   - 也可以是消完一组后，下一组自然露出；
   - 这意味着棋盘上至少要有多个 `2/3` 的潜在对子。
3. 第 `5` 步左右可以设置一个小门槛：玩家必须先挪一个砖、打开一个位置，才能继续消一组。
4. 如果一局约 `24` 步，可以在消完第 `4` 组、第 `9` 组附近设置类似小门槛。
5. 可消砖块不应集中在一块区域，应分布在左、右、上、下、中，让玩家眼睛动线覆盖整个棋盘。
6. 可以设置“关键 tile”：只要消掉这个关键 tile，后面会明显打开，其他部分更顺。

## 2. 是否应该加入

结论：应该加入。

这些原则不是单独的新机制，而是普通棋盘的“流程编排规则”。它们可以进入我们目前的四层核心架构：

```text
结构层：关键 tile 控制暴露路径
图案层：可消组 / 2+1 / 2+2+1 分布
压力层：前 4 步顺、第 5 步门槛、第 4/9 组释放节奏
验证层：自动检查开局可消组、空间分布、关键 tile 是否有效
```

它们比“单纯让棋盘形状好看”更进一步：开始控制玩家实际游玩路线。

## 3. 设计术语定义

### 3.1 Immediate Match / 立即可消组

进入关卡第一眼，不需要先挪其他砖，就能直接消掉的一组三消。

建议：

```text
开局立即可消组：2-3 组
对应可消砖块：6-9 个
```

如果超过太多，开局会变成无脑清；如果太少，开局会卡。

### 3.2 Candidate Pair / 潜在对子

当前可见或浅层可见的 `2/3` 组合。

它的作用是让玩家形成目标：

```text
我已经看到两个 A，只要打开第三个 A 就能消。
```

建议：

```text
开局潜在对子：3-5 个
```

### 3.3 Chain Match / 连续消除链

玩家消完一组后，下一组或下一个 `2/3` 目标自然出现。

目标：

```text
前 4 步基本能连续消除，不要频繁断流。
```

### 3.4 Soft Gate / 小门槛

不是硬锁，也不是机制障碍，而是轻微策略点：

```text
玩家必须先点一个暂时不立刻三消的砖，打开下面的关键第三张。
```

建议位置：

```text
第 5 步左右第一次出现。
消完第 4 组、第 9 组后各出现一次轻门槛。
```

### 3.5 Key Tile / 关键 tile

关键 tile 是一个“打开局面”的砖。

它通常满足：

- 被消掉后露出 1-2 个重要第三张；
- 或者释放某个局部区域；
- 或者让多个 `2/3` 目标变成可消组；
- 玩家消掉它后会感觉局面突然变顺。

关键 tile 不一定是特殊机制，仍然可以是普通砖。

## 4. 推荐节奏模型

假设一关大约 `24` 步，可以先用下面节奏：

| 阶段 | 步数 / 组数 | 体验目标 | 设计手段 |
|---|---|---|---|
| 开局爽点 | 第 1-4 步 | 连续消、建立信心 | 2-3 个立即可消组 + 3-5 个潜在对子 |
| 第一次小门槛 | 第 5 步 / 第 4 组后 | 轻策略，不让玩家一路无脑点 | 需要先挪 1 个砖打开第三张 |
| 中段展开 | 第 6-12 步 | 左右上下多区域切换 | 可消组分布在不同区域 |
| 第二次小门槛 | 第 9 组后 | 制造轻压力和目标感 | 关键 tile 打开一个局部区域 |
| 后段释放 | 最后 25%-30% | 让玩家感觉“打开了” | 关键 tile 后连续释放 2-3 组 |
| 收束 | 最后几组 | 不拖沓 | 剩余图案不要太散 |

## 5. 空间动线规则

可消组不能全部集中在一个区域。

建议把棋盘分成 5 个区域：

```text
左区 / 右区 / 上区 / 下区 / 中央区
```

开局 `2-3` 个立即可消组最好覆盖至少 `2-3` 个区域。

潜在对子最好覆盖至少 `3-4` 个区域。

高分结构应该让玩家眼睛这样移动：

```text
左上 → 中央 → 右侧 → 下方 → 回到中央
```

或者：

```text
左侧小消除 → 右侧小消除 → 中央关键 tile → 下方释放
```

不建议：

```text
所有可消组都在左下角。
玩家只盯着一块地方点。
其他区域像背景。
```

## 6. 关键 tile 设计规则

### 6.1 关键 tile 的数量

前期关卡：

```text
1 个关键 tile 即可
```

中期关卡：

```text
2 个关键 tile
```

后期或高峰关：

```text
2-3 个关键 tile，但不要互相锁死
```

### 6.2 关键 tile 的位置

关键 tile 不宜放在最深层，也不宜开局就直接暴露成无脑消。

推荐：

```text
浅层遮挡 1-2 步后可达
位于中央桥、左右连接点、局部塔的底部/中层
```

### 6.3 关键 tile 的效果

消掉关键 tile 后，至少产生一个明显效果：

- 露出一个立即三消组；
- 补齐两个 `2/3` 目标中的第三张；
- 打开一个区域入口；
- 降低槽位压力。

## 7. 与研究/理论的关系

目前没有必要声称存在一套专门针对 Tile Match 的公开公式，但这些原则和几个成熟研究方向一致。

### 7.1 视觉搜索与注意力分配

视觉搜索研究认为，人不会一次性高质量处理整个画面，而是会被颜色、位置、形状、目标显著性引导注意力。棋盘上的可消组如果分散在多个区域，可以引导玩家扫视全局，而不是只盯一块区域。

可参考：

- Nature Human Behaviour: “Five factors that guide attention in visual search”  
  https://www.nature.com/articles/s41562-017-0058
- Wolfe 的 Guided Search 视觉搜索模型相关研究。

对应到 tile 关卡：

```text
可消组 / 潜在对子 / 关键 tile 应作为注意力锚点，分布在多个区域。
```

### 7.2 心流与挑战-技能平衡

游戏心流理论强调：玩家体验最好时，挑战与能力相匹配，有清晰目标和即时反馈。前 4 步顺畅、第 5 步轻门槛，就是在做“先建立掌控感，再给适度挑战”。

可参考：

- Jenova Chen, Flow in Games  
  http://jenovachen.com/flowingames/Flow_in_games_final.pdf
- Flow in Games and Everything Else  
  https://www.jenovachen.com/flowingames/p31-chen.pdf

对应到 tile 关卡：

```text
开局连续消除 = 建立掌控感
小门槛 = 适度挑战
关键 tile 后释放 = 即时反馈和成就感
```

### 7.3 认知负荷

眼动和认知负荷研究通常会用注视分布、扫视路径、任务表现等指标来衡量信息处理负担。Tile 棋盘如果所有目标集中在一处，会减少全局扫描；如果目标过散又会增加负担。合理做法是让目标分布覆盖全局，但保持数量可控。

对应到 tile 关卡：

```text
不是让玩家到处乱找，而是用 2-3 个立即可消组 + 3-5 个潜在对子，建立有方向的全局扫描。
```

## 8. 可执行检查指标 v0.1

后续生成器/校验器可以先加这些指标：

### 8.1 开局指标

```text
openingImmediateMatches: 2-3
openingImmediateTiles: 6-9
openingCandidatePairs: 3-5
openingCoveredRegions: >= 3 个区域
```

### 8.2 前 4 步指标

```text
firstFourStepsCanChain: true
firstFourStepsMatchCount: >= 3
firstFourStepsDeadGap: 0
```

含义：前 4 步不应出现“无目标、必须乱点”的断流。

### 8.3 小门槛指标

```text
softGateAfterMatchGroup: [4, 9]
softGateCostTiles: 1-2
softGateUnlocksMatches: >= 1
```

含义：小门槛只需要先挪 1-2 个砖，之后应该打开至少一组可消。

### 8.4 空间分布指标

```text
immediateMatchRegionCount >= 2
candidatePairRegionCount >= 3
keyTileRegionCount >= 1
allTargetsInOneRegion = false
```

### 8.5 关键 tile 指标

```text
keyTileCount: 1-2
keyTileDepth: 1-3 步可达
keyTileUnlocks: >= 1 组立即三消 或 >= 2 个潜在对子
```

## 9. 质量模型更新建议

把 `flowScore` 细化为：

- 开局 2-3 组可消。
- 前 4 步不断流。
- 第 5 步出现轻门槛。
- 第 4/9 组后有小门槛或关键 tile。
- 后段有释放，不拖尾。

把 `pressureScore` 细化为：

- 小门槛造成轻压力，但必须可恢复。
- 关键 tile 消除后应释放压力。
- 槽位压力来自 `2/3` 目标，而不是恶意卡死。

把 `visualScore / shapeScore` 补充：

- 可消目标分布覆盖多个区域。
- 玩家视线会自然扫过左、右、上、下、中。

## 10. 当前结论

用户这组原则非常适合加入。

它们本质上定义了：

```text
关卡不是静态棋盘，而是一条可控的消除路径。
```

下一步如果要落地到代码，建议先不直接改所有关卡，而是给 `Level 1-5` 做一版“开局流样板”：

1. 开局 2-3 组直接可消。
2. 前 4 步不断流。
3. 第 5 步有 1 个小门槛。
4. 可消组分布在 3 个以上区域。
5. 每关 1 个关键 tile。

然后在 Cocos 真实体验里验证是否更像竞品。
